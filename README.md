- 向僵尸开炮
  - 自动刷环球、关卡
  - 仅保留智能版，双击 start.bat 或执行 python game_bot_smart.py
  - 打包执行 build_game_bot_smart.bat，生成 dist/start_game_smart.exe
    - 战斗次数：默认 0 表示无限循环。
    - 界面顶层模式：寰球救援、关卡模式。
    - 寰球救援的入队方式：频道招募、副本邀请（接受难度最高的寰球救援邀请）。两种方式共用战斗流程。
    - 基础配置（base）：窗口标题、模式、寰球入队方式和组队等待时间，只负责入口。mode：0 为寰球救援，1 为关卡模式；huanqiu_entry：channel 为频道招募，invite 为副本邀请。
    - 战斗模式配置（battle）：战斗次数、单场时间限制、技能优先级、生化子弹优先和自动退出规则。所有入口共用一份配置，切换入口不改变战斗设置。
    - 模式误入退出（exit_on_mode_mismatch）：选择寰球救援时，识别出关卡或深渊同行就退出；选择关卡模式时，识别出寰球救援或深渊同行就退出。未明确识别时继续观察，不将识别失败当成其他模式。旧版两项退出开关会合并迁移。
    - 配置模型位于 bot_config.py，运行时分别传入 BaseConfig 和 BattleConfig。支持自动读取旧版扁平配置及 mode=3 的邀请模式配置。
  - 仅支持Windows PC端微信小程序
  - 用的opencv图像对比,兼容性较差
  - 推荐窗口大小542*1028，已支持不同 Windows 显示缩放比自动适配
- 代码仅供学习参考,勿分享滥用
